🗂️ AuraDirect (zentrale Benutzerverwaltung)

Optional - falls eingerichtet, prüft die Anmeldung zuerst dort (inkl. Active-Directory-Anbindung). Ohne Eintrag läuft alles wie bisher rein lokal.

💬 Zeiterfassung per Chat/Sprache (AuraChat)

Diesen Schlüssel in AuraChat eintragen (Admin Panel → API → "AuraPlan verbinden"), damit Ein-/Ausstempeln, Ferienanträge und Schichtplan-Abfragen per Chat oder Sprachbefehl möglich werden.

🔒 Domains und Zertifikate

Domain, https und Zertifikate werden zentral im AuraProxy verwaltet (Let's Encrypt für öffentliche Domains, eigene Zertifizierungsstelle für interne Namen). AuraPlan selbst spricht nur HTTP auf Port 3002 und wird vom AuraProxy weitergeleitet.

💾 Backup

Lädt die komplette AuraPlan-Datenbank herunter (Mitarbeiter, Zeiterfassung, Schichtpläne, Ferien, Einstellungen).

⚠️ Wiederherstellen

Ersetzt die komplette aktuelle Datenbank durch den Inhalt der hochgeladenen Sicherung. Der Server startet danach automatisch neu.

📤 Export

Als CSV-Datei herunterladen (öffnet sich direkt in Excel). Zeiterfassung/Schichtplan/Ferien optional auf einen Zeitraum eingrenzen.

🔌 Externe API

Lesezugriff für Drittsysteme (z.B. Buchhaltungsprogramme) auf Mitarbeiter, Zeiterfassung und Absenzen als JSON. Anfragen brauchen den Header X-API-Key. Endpunkte: /api/external/employees, /api/external/time-entries?from=&to=, /api/external/absences?from=&to=.
