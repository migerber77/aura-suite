Ein Befehl installiert alles: Oberfläche, Server, HTTPS, Web-Suche und Sprache. Kostenlos starten mit bis zu 3 Benutzern — jederzeit auf Premium erweiterbar.

// 1. Einmalig: eigene Schlüssel erzeugen (gut aufbewahren)
printf "SESSION_SECRET=%s\nDISPOSITION_ENCRYPTION_KEY=%s\n" "$(openssl rand -hex 32)" "$(openssl rand -hex 32)" > .env
// 2. Alles installieren und starten
docker compose -p aurachat --env-file .env -f oci://docker.io/migerber77/aurachat:latest up -d
// Später aktualisieren
docker compose -p aurachat --env-file .env -f oci://docker.io/migerber77/aurachat:latest pull && docker compose -p aurachat --env-file .env -f oci://docker.io/migerber77/aurachat:latest up -d

Voraussetzung: Docker Engine 25 oder neuer. Auf älteren Systemen (z.B. manche NAS) stattdessen die Compose-Datei herunterladen und mit „docker compose up -d“ starten.

Aura-Suite: Installation & Deployment

So richtest du die Aura-Suite auf einem neuen Server aus dem GitHub-Repository ein und startest sie.

Voraussetzungen

  • Ein Linux-Server (z. B. Ubuntu oder Debian)
  • Docker und Docker Compose sind auf dem Zielsystem installiert
  • Git ist installiert

Schritt 1: Repository klonen

Klone das zentrale Repository auf deinen Server in das gewünschte Verzeichnis (z. B. /docker/aura-suite):

sudo mkdir -p /docker
cd /docker
git clone https://github.com/migerber77/aura-suite.git
cd aura-suite

Schritt 2: Umgebungsvariablen (.env) einrichten

Zugangsdaten und Passwörter liegen aus Sicherheitsgründen nicht im Repository. Lege die benötigten .env-Dateien deshalb lokal an:

  1. Suche in den Unterordnern nach den bereitgestellten Vorlagen (z. B. .env.example).
  2. Kopiere sie als .env und trage deine eigenen Werte und Passwörter ein (Beispiel für einen Dienst):
cp .env.example .env
nano .env

Schritt 3: Docker-Container starten

Sind alle .env-Dateien angelegt, startest du die Suite im Hintergrund:

docker compose up -d --build

Prüfe danach, ob alle Container gestartet sind und fehlerfrei laufen:

docker compose ps

Schritt 4 (optional): Automatischer Git-Sync

Soll der Server Änderungen selbst erfassen und synchronisieren, kannst du das mitgelieferte Skript per Cronjob einrichten. Für normale Installationen ist das nicht nötig.

1. Adresse des Repositorys mit Token setzen (nur wenn Schreibrechte nötig sind):

git remote set-url origin https://DEIN_TOKEN@github.com/migerber77/aura-suite.git

Achtung: Der Token steht danach im Klartext in .git/config. Erzeuge ihn nur für dieses Repository und mit den geringsten Rechten. Prüfe außerdem vorher, dass .env-Dateien und Datenordner in der .gitignore stehen, damit der Sync keine Passwörter oder Daten überträgt.

2. Cronjob für den stündlichen Sync einrichten (crontab -e) und diese Zeile am Ende einfügen:

0 * * * * /docker/aura-suite/git-sync.sh >> /docker/aura-suite/sync.log 2>&1

Alles, was ein Team-Assistent können sollte — und einiges, was sonst keiner kann.

Aura geht ans Telefon.

AuraCall verbindet eure Telefonnummer mit AuraChat: Aura nimmt Anrufe entgegen, versteht, was gesagt wird, und antwortet mit Stimme — auf euren eigenen Servern. Auf Wunsch ruft Aura auch selbst an, zum Beispiel um eine Nachricht auszurichten.

Ein Telefonassistent, der sich an die Regeln hält.

📞

Anrufe entgegennehmen

Aura begrüsst die Anrufenden, macht von Anfang an klar, dass sie eine KI ist, hört zu, beantwortet Fragen und verabschiedet sich. Auch Unterbrechen mitten im Satz ist möglich.

🧠

Das Wissen eures Betriebs

Öffnungszeiten, Preise, Anreise: ihr legt fest, was Aura am Telefon weiss. Weiss sie etwas nicht, sagt sie das ehrlich und bietet einen Rückruf an.

📤

Ausgehende Anrufe

Aura ruft Nummern an und richtet Nachrichten aus — sofort oder zu einer geplanten Zeit. Grenzen für Länder, Uhrzeiten, Anzahl und Sondernummern verhindern Missbrauch und unerwartete Kosten.
