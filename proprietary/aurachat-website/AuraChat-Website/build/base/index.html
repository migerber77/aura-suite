Holt euch heute noch AuraChat.

Fertiges Docker-Image, ein Befehl, läuft. Kostenlos starten mit bis zu 3 Benutzern — jederzeit auf Premium erweiterbar.

// 1. Quickstart-Paket herunterladen und entpacken
curl -O http://aurachat.gerber-backoffice-solutions.com/downloads/aurachat-quickstart.zip
unzip aurachat-quickstart.zip -d aurachat && cd aurachat
// 2. Eigene Geheimwerte eintragen
cp .env.example .env && nano .env
// 3. Starten
docker compose up -d

Chat & KI

Anbindung an Ollama, LM Studio, llama.cpp, OpenAI-kompatible Server oder OpenAI Cloud. Websuche direkt im Chat, optionales Zweitmodell zur Genauigkeitsprüfung.

🎭

Avatar & Stimme

Ein sprechender Video-Avatar mit eigener Stimme. Fünf Charaktere inklusive, eigene Avatare möglich. "Hey Aura" aktiviert sich freihändig per Zuruf.

🧠

Gedächtnis & Persönlichkeit

Merkt sich relevante Fakten automatisch. Jede Person kann Auras Charakter für ihr eigenes Konto frei gestalten. Täglicher Rückblick auf Wunsch.

📎

Produktivität

Eigene Dokumente als Kontext, Chat-Export als PDF, automatische Lernprotokolle, Quiz aus jedem Gespräch, Erinnerungen per Zuruf.

🔌

Integrationen

Smart-Home-Steuerung, Sonos, E-Mail per IMAP oder Microsoft 365 inklusive KI-Antwortentwürfen, offene API für externe Plattformen.

🛠️

Administration

Mehrere Administratorkonten mit eigener Lizenz-Auslastungsanzeige, automatisches SSL auf Standard-Ports 80/443, Zwei-Faktor-Authentifizierung, versionierte Datenschutzerklärung.

💾

Betrieb & Wartung

Ein-Klick-Backup als Download, Wiederherstellung direkt im Admin Panel, Selbst-Update per Upload inklusive automatischer Syntaxprüfung und Sicherung vor jeder Änderung.

🏷️

White-Label

Eigenes Logo & Icon statt AuraChat-Branding — wirkt überall: Kopfzeile, Login, Favicon, PDF-Exporte. Ideal für Wiederverkäufer.
